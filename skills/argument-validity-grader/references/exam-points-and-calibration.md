# 命题要点与严格评分校准

资料核验日期：2026-09-27。本文件供完整输入下的论效批改使用，不放宽“材料与作文必须齐全”的前置条件。

## 一、来源与效力

1. **考试机构公开说明**：教育部教育考试院《中国教育考试网·管理类综合能力》。说明论效要求识别有缺陷的论证并选择若干点评论，考查分析、论证能力；检查概念、推理、证据支持和成立条件等。这是题型与能力要求，不是每题完整评分答案。
   来源：`https://yankao.neea.edu.cn/xhtml1/report/21115/4951-1.htm`
2. **出版社公开样章**：清华大学出版社《2018 MBA、MPA、MPAcc等管理类联考英语词汇速记手册》所附考试大纲与题型示例，印刷页26~27。其论效示例的内容参考列出6项，说明“材料可分析点数”不等于考生必须逐项穷尽的数量。它不是对所有年份、所有题目的固定点数规定。
   来源：`https://www.tup.tsinghua.edu.cn/upload/books/yz/074504-01.pdf`
3. **经综公开大纲转载**：巨鹰考研《经济类专业学位联考综合能力考试大纲》（2019-12-11），写作部分同样要求选择若干要点分析，并强调分析有效、理由充分、结构严密、语言得当。作为辅证，不能据此推出经综采用管综分项同比例换算的官方细则。
   来源：`https://www.juyingonline.com/news/332062.html`

本地规则的边界：

- “一般有6~7个出题点”是用户指定的全面检查预期；上述资料能支持存在多个可选分析点，不能证明每份材料固定6~7点。独立核验后可以少于6点或多于7点。
- 内容16分、另项14分、取最高4个独立点及经综乘以2/3，沿用用户既有训练量表。0~4分细化及更严格的一类门槛为本次训练校准，不冒称官方阅卷细则。
- 材料中6~7个候选点，不意味着将16分平均分给6~7点，也不意味着只有覆盖全部候选点才能高分。
- 以下例子均为自拟校准，不是历年真题或官方标准答案。

## 二、逐层排查的着眼点

| 材料中的推理 | 需要核验的具体问题 | 不可机械套用的质疑 |
| --- | --- | --- |
| 同一词语贯穿不同段落 | 主体、含义、时间、数量范围是否改变，改变是否影响推论 | 只因换了近义词就判偷换概念 |
| “只要”“只有”“必须”“可能”等条件句 | 前提究竟必要还是充分，有无把可能增强为必然，结论是否超出条件 | 不看限定词便反驳绝对化 |
| 用例子、调查、统计支持总体判断 | 样本选择和代表性、统计口径、分母、基期、比例与绝对量是否足以支持该结论 | 凡出现数据就说不可靠，凡出现样本就说太小 |
| 先后变化、相关关系或不同群体比较 | 是否存在因果归因，是否排除相关混杂因素、逆向关系及选择效应 | 将题目给定的因果事实本身一概否认 |
| 比较对象、借鉴经验、跨时空外推 | 与结论有关的关键条件是否可比，局部成功能否推广 | 罗列无关差异而不解释影响 |
| 由描述推到建议、效果或收益 | 措施是否足以实现目标，资源约束、执行条件、副作用是否影响结论 | 改写为自己的政策主张，或凭空要求穷尽所有因素 |
| 多条理由汇总为最终结论 | 各理由是否实际支持结论，有无自相矛盾、非此即彼、整体与部分混淆 | 将同一个遗漏分别包装成多个逻辑标签 |

该表是核查路径，不是七个必有的考点。一个维度可能没有点，也可能含多个真正独立的推理缺口。

## 三、分值边界示例

自拟材料：“某企业实行弹性工作制后，员工离职率下降，因此离职率下降完全是弹性工作制带来的。”

| 考生实际表述 | 校准判定 |
| --- | --- |
| “材料不科学，缺乏数据，犯了因果错误。” | 0分。未具体定位并解释推理缺口，仅贴标签。 |
| “实行弹性工作制后离职率下降，不等于下降是弹性工作制造成的。” | 1分。准确指向归因跳跃，但尚无具体理由。 |
| “实行弹性工作制后离职率下降，还可能与其他因素有关，例如办公室装修。” | 2分。提出具体替代因素，但未说明它如何影响离职率及当前归因，联系尚不足。不得替考生补理由。 |
| “同期提高工资也会增强员工留任意愿，因此离职率下降与弹性工作制无关。” | 3分。他因及作用方向具体，确能挑战完全归因；但把未排除他因推进为完全无关，结论越界。 |
| “同期若提高工资，也可能增强员工留任意愿并降低离职率；材料未排除这一影响，仅凭实行前后的变化，不能把下降完全归因于弹性工作制。” | 4分。替代解释与原结论有直接关系，使用合理可能性，解释了缺口，不武断否定弹性工作制的作用。 |

不得把模板当标准措辞：只要其他表述已传达同样完整且准确的推理，也能得4分。合理可能性不需要外部调查证明确实发生。

## 四、独立性与综合质量

- 同一材料中，以“工资变化”“外部就业机会减少”分别挑战同一“完全归因”，通常是一个归因缺口的两种解释，不自动算两点。
- 若材料还由“本企业效果”推出“所有行业普遍有效”，样本或推广条件可构成另一个独立缺口。与前述归因点应分开核验。
- 一个段落可以含多个独立点；多个段落也可能只共同完成一个点。先合并同一缺口的有效文字，再选最高4项，不按段数计数。
- 4个4分要点，内容16分；7个均为1分的独立要点，内容取最高4项只有4分；同一点写4次，最多只有该点的一份内容分。经综总分始终在合计C与Q之后再乘2/3。
- 内容达到4分的最低完整性不自动意味着解释深入。B项还看主要段落是否具体、有力、简洁、连贯；但不能因不使用固定模板而认定力度不足。
- 内容与B项不能为同一缺陷机械扣两遍。例如某点理由不完整已计2分，不再设置“该点另扣B项2分”的罚则；只有全文反复浅析、论证推进不足等独立整体表现，才作为B项档位和档内取分依据。
- 参考答案之外有成立点时可补入材料表。仍有歧义或高度依赖额外设定的候选点，只标争议和解释，不据此认定考生必然漏答。
