# 经综作文批改/管综作文批改/考研英语二作文批改skill-基于gpt6实现
本skill完全基于ai，作者无任何技术基础，一切技术问题不予讨论。下示安装流程基于ai，实际可行性未验证，如遇问题可下载完整项目后自行询问ai

三项作文批改 Skill，分别用于 **396 经综论说文**、**经综 / 管综论证有效性分析** 和 **考研英语二写作**。经综论说满分20，管综同学可自行换算。批改结合题目和原文解释得分，按作文类型检查论证、任务完成度、结构与语言，给出可以落实到句子和段落的修改，并在批改后附一篇完整参考范文。

这是学习训练用的评分与反馈流程，不是官方阅卷系统，也不代表官方统一评分细则。AI 评分存在主观性和误判可能，不能作为实际考试成绩的保证。

## 选择哪个 Skill

| Skill | 作文类型 | 必需输入 | 评分口径 |
| --- | --- | --- | --- |
| [`econ396-essay-grader`](skills/econ396-essay-grader/SKILL.md) | 396 经综论说文 | 完整题目材料和本人完整作文，缺一不可 | 名义满分20分，训练评分最高18分 |
| [`argument-validity-grader`](skills/argument-validity-grader/SKILL.md) | 经综 / 管综论证有效性分析 | 完整原题材料和本人完整作文，缺一不可 | 管综30分；经综按相同比例换算为20分 |
| [`english2-writing-grader`](skills/english2-writing-grader/SKILL.md) | 考研英语二A节应用文、B节短文 | 完整题目（含相关图表）和考生原作 | A节10分、B节15分；两节合计25分 |

三个 Skill 独立使用，不能混用评分量表。正式评分均须具备对应题目和考生原作：缺项时先补齐，不给暂定评分。经综、管综两项缺材料时也不先做局部批改；英语二可在用户明确只要求语言修改时修改已给文本，但不据此给考试分数。当前对话中已提供的对应完整原文可以沿用；题目标题、作文转述、参考答案和范文不能代替原题材料。

输入齐全后，默认先完成评分、分析与修改，再输出同题范文，无需另行索取。中文作文范文包含标题和完整正文，英语二范文按题面和文体安排标题及应用文格式，均遵守原题写作要求。范文质量不计入原作分数，也不代表官方答案或满分保证。缺少材料或作文时不先写范文。当次明确要求不提供范文时，可省略范文。

## 安装

### 让 Codex 安装

把本仓库的 GitHub 链接与下面这段话一起发给 Codex：

```text
请使用 $skill-installer，从这个 GitHub 仓库安装三个 Skill：
skills/econ396-essay-grader
skills/argument-validity-grader
skills/english2-writing-grader
```

安装完成后，在下一轮对话中调用对应的 Skill。

### 手动安装

下载本仓库，将 `skills/` 下需要的 Skill 文件夹完整放入自己的 Codex Skills 目录：

- 默认目录：`~/.codex/skills/`。
- Windows 默认目录：`%USERPROFILE%\.codex\skills\`。
- 设置过 `CODEX_HOME` 时，使用该目录下的 `skills/`。

请保留每个文件夹内的 `SKILL.md`、`agents/openai.yaml` 及存在的 `references/` 目录。如果已经安装同名 Skill，更新前请先检查并保留自己的修改。

## 使用示例

### 396 经综论说文

```text
请使用 $econ396-essay-grader 批改我的396经综论说文。

题目材料：
[粘贴完整题目材料及题面附带的写作要求]

标题：
[作文标题]

我的文章：
[按原段落粘贴完整作文]
```

反馈包括：先定档、分项评分、审题评价、逐段逻辑分析、具体修改、提分重点，最后附一篇完整论说文参考范文。

- 内容8分、结构6分、语言4分、其他2分，最终最高18分。
- 参考范文的标题与正文合计须为700～750字（含上下限），标点计入总字数；汉字、标点、数字和英文字母均逐字符计数，空白字符、Markdown排版标记、栏目名及批改说明不计入。交付前实际计数，修改后重新核验；当次另有明确字数要求时按该要求。
- 缺少完整材料或完整作文时先补齐，不给暂定评分，不进行局部批改，不猜测原题。
- 重点检查论据是否支持论点、因果与条件是否充分、段落是否真正推进论证。
- 已确认的错字每3个扣1分，最多扣2分，并避免重复扣分。
- 纯文本不能核验手写字迹；识别不清的字不会直接作为错字处罚。

### 论证有效性分析

```text
请使用 $argument-validity-grader 批改我的论证有效性分析作文。

考试类型：
[经综或管综]

原题论证材料：
[粘贴完整原题材料及题面附带的写作要求]

我的文章：
[标题与完整正文]

参考答案：
[可选；没有参考答案也可以批改]
```

反馈包括：分项评分、材料考点梳理、作文分析要点核验、论证与结构语言评价、关键句段修改，最后附一篇完整论证有效性分析参考范文。

- **完整原题材料与完整作文缺一不可，缺项不批改，也不给暂定分。**
- 管综：分析评论内容16分，论证程度、结构与语言综合14分，总分30分。
- 先独立全面检查材料，按通常可能有6~7个候选点的预期排查，但不硬凑数量，也不要求作文写满全部候选点。
- 内容取最好的4个独立分析：只有推理对象准确、缺口成立、理由具体且说明削弱关系，才算完整命中并得4分。4个完整命中取得内容16分；只报术语、泛泛反问或重复换说法不能充数。
- 单点区分完整命中4分、基本命中3分、部分命中2分、仅定位1分、未命中0分。该细化及6~7点检查预期属于本地训练规则，不冒充官方补充细则。
- 合理且成立的分析即使不在参考答案中，也可以得分。
- 综合质量项的一类卷须有持续、具体、有力的分析；不能仅凭段落整齐、语言流畅取得高档分，同一缺陷不机械重复扣分。
- 四类卷仅对应14分的综合质量项，不是整篇总分的档位。
- 经综：先按30分制评定，再将总分乘以 `2/3`，满分20分；不采用论说文的18分封顶。

公开资料依据、命题检查路径和自拟评分示例见[命题要点与严格评分校准](skills/argument-validity-grader/references/exam-points-and-calibration.md)。公开资料支持选择若干有效分析点，不规定每份材料固定6~7点；经综同比例换算沿用本项目的训练量表。

### 考研英语二作文

```text
请使用 $english2-writing-grader 批改我的考研英语二作文。

节别：
[A节小作文或B节大作文；两节可同时提供]

完整题目：
[粘贴情景、提纲、全部写作要求；图表题同时提供清晰图表或完整转录]

我的作文：
[按原段落粘贴原作，保留称呼、落款等实际格式]
```

反馈包括：先定档再给分、题目要点核对、逐段评价与具体语言纠错、提分重点，以及符合原题要求的完整英文参考范文。

- A节小作文正文须为101—114词（大于100词且小于115词）、满分10分，重点是信息覆盖、内容组织、语言准确性、格式和语域。
- B节大作文正文须为151—159词（大于150词且小于160词）、满分15分，重点是内容完整、组织连贯、语法词汇多样性和准确性；图表题会核对趋势、数据和单位。
- 按第五档至零档整体评分，不自行编造分项权重、满分禁令或逐错扣分表。
- 上述区间是用户指定的硬性训练要求，适用于原作检查、完整修改稿和参考范文，称呼、落款和标题不计入正文；不宣称是官方统一合格线。原作字数未达标须明确指出并酌情处理，修改稿和范文须核算至达标后交付。A节可使用提示语个别关键词或词组，照抄完整句子须结合题面对照处理。
- 英式、美式拼写和词汇均可接受；纯文本不扣手写卷面分，确因书写较差影响理解时按标准降一档。
- 参考范文及词数统计用于学习训练，不倒算进原作成绩。

本 Skill 依据创建时用户提供的[英语二写作评分标准](skills/english2-writing-grader/references/scoring-rubric.md)整理，不冒充对任何年度最新评分文件的核验，也不适用于英语一。
