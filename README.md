# 经综与管综作文批改 Skills

两项中文作文批改 Skill，分别用于 **396 经综论说文** 和 **经综 / 管综论证有效性分析**。批改重点是结合原文解释得分、识别推理缺口，并给出可以落实到句子和段落的修改。

这是学习训练用的评分与反馈流程，不是官方阅卷系统，也不代表官方统一评分细则。AI 评分存在主观性和误判可能，不能作为实际考试成绩的保证。

## 选择哪个 Skill

| Skill | 作文类型 | 必需输入 | 评分口径 |
| --- | --- | --- | --- |
| [`econ396-essay-grader`](skills/econ396-essay-grader/SKILL.md) | 396 经综论说文 | 本人作文；题目材料可选 | 名义满分20分，训练评分最高18分 |
| [`argument-validity-grader`](skills/argument-validity-grader/SKILL.md) | 经综 / 管综论证有效性分析 | 原题材料和本人作文，缺一不可 | 管综30分；经综按相同比例换算为20分 |

两个 Skill 独立使用，不能混用评分量表。

## 安装

### 让 Codex 安装

把本仓库的 GitHub 链接与下面这段话一起发给 Codex：

```text
请使用 $skill-installer，从这个 GitHub 仓库安装两个 Skill：
skills/econ396-essay-grader
skills/argument-validity-grader
```

安装完成后，在下一轮对话中调用对应的 Skill。

### 手动安装

下载本仓库，将 `skills/` 下的两个文件夹完整放入自己的 Codex Skills 目录：

- 默认目录：`~/.codex/skills/`。
- Windows 默认目录：`%USERPROFILE%\.codex\skills\`。
- 设置过 `CODEX_HOME` 时，使用该目录下的 `skills/`。

请保留每个文件夹内的 `SKILL.md` 和 `agents/openai.yaml`。如果已经安装同名 Skill，更新前请先检查并保留自己的修改。

## 使用示例

### 396 经综论说文

```text
请使用 $econ396-essay-grader 批改我的396经综论说文。

题目材料：
[粘贴材料；没有材料时明确说明未提供]

标题：
[作文标题]

我的文章：
[按原段落粘贴完整作文]
```

反馈包括：先定档、分项评分、审题评价、逐段逻辑分析、具体修改和提分重点。

- 内容8分、结构6分、语言4分、其他2分，最终最高18分。
- 缺少材料时给暂定评分，不猜测原题，不直接认定跑题。
- 重点检查论据是否支持论点、因果与条件是否充分、段落是否真正推进论证。
- 已确认的错字每3个扣1分，最多扣2分，并避免重复扣分。
- 纯文本不能核验手写字迹；识别不清的字不会直接作为错字处罚。

### 论证有效性分析

```text
请使用 $argument-validity-grader 批改我的论证有效性分析作文。

考试类型：
[经综或管综]

原题论证材料：
[粘贴完整材料]

我的文章：
[标题与完整正文]

参考答案：
[可选；没有参考答案也可以批改]
```

反馈包括：分项评分、分析要点核验、论证与结构语言评价、关键句段修改。

- **没有原题材料不能批改，也不给暂定分。**
- 管综：分析评论内容16分，论证程度、结构与语言综合14分，总分30分。
- 4个独立且正确的分析要点取得内容16分；重复表述不重复计分。
- 每个要点0~4分、部分命中酌情计分，是本 Skill 为训练设置的操作细化，不冒充官方补充细则。
- 合理且成立的分析即使不在参考答案中，也可以得分。
- 四类卷仅对应14分的综合质量项，不是整篇总分的档位。
- 经综：先按30分制评定，再将总分乘以 `2/3`，满分20分；不采用论说文的18分封顶。

仓库只包含批改规则和使用说明，不附个人作文、考试试卷、账号凭据或本机路径。
