# 经综作文批改/管综作文批改skill-基于gpt6实现
本skill完全基于ai，作者无任何技术基础，一切技术问题不予讨论。下示安装流程基于ai，实际可行性未验证，如遇问题可下载完整项目后自行询问ai

两项作文批改 Skill，分别用于 **396 经综论说文** 和 **经综 / 管综论证有效性分析**。经综论说满分20，管综同学可自行换算。批改重点是结合原文解释得分、识别推理缺口，并给出可以落实到句子和段落的修改。

这是学习训练用的评分与反馈流程，不是官方阅卷系统，也不代表官方统一评分细则。AI 评分存在主观性和误判可能，不能作为实际考试成绩的保证。

## 选择哪个 Skill

| Skill | 作文类型 | 必需输入 | 评分口径 |
| --- | --- | --- | --- |
| [`econ396-essay-grader`](skills/econ396-essay-grader/SKILL.md) | 396 经综论说文 | 完整题目材料和本人完整作文，缺一不可 | 名义满分20分，训练评分最高18分 |
| [`argument-validity-grader`](skills/argument-validity-grader/SKILL.md) | 经综 / 管综论证有效性分析 | 完整原题材料和本人完整作文，缺一不可 | 管综30分；经综按相同比例换算为20分 |

两个 Skill 独立使用，不能混用评分量表。两者均不能只给作文：缺少材料或作文时先补齐，不给暂定评分，也不先做语言、结构等局部批改。当前对话中已提供的对应完整原文可以沿用；题目标题、作文转述、参考答案和范文不能代替原题材料。

## 安装

### 让 Codex 安装

把本仓库的 GitHub 链接与下面这段话一起发给 Codex：

```text
请使用 $skill-installer，从这个 GitHub 仓库安装两个 Skill：
skills/econ396-essay-grader
skills/argument-validity-grader
```

安装完成后，在下一轮对话中调用对应的 Skill。

### 手动安装

下载本仓库，将 `skills/` 下的两个文件夹完整放入自己的 Codex Skills 目录：

- 默认目录：`~/.codex/skills/`。
- Windows 默认目录：`%USERPROFILE%\.codex\skills\`。
- 设置过 `CODEX_HOME` 时，使用该目录下的 `skills/`。

请保留每个文件夹内的 `SKILL.md`、`agents/openai.yaml` 及存在的 `references/` 目录。如果已经安装同名 Skill，更新前请先检查并保留自己的修改。

## 使用示例

### 396 经综论说文

```text
请使用 $econ396-essay-grader 批改我的396经综论说文。

题目材料：
[粘贴完整题目材料及题面附带的写作要求]

标题：
[作文标题]

我的文章：
[按原段落粘贴完整作文]
```

反馈包括：先定档、分项评分、审题评价、逐段逻辑分析、具体修改和提分重点。

- 内容8分、结构6分、语言4分、其他2分，最终最高18分。
- 缺少完整材料或完整作文时先补齐，不给暂定评分，不进行局部批改，不猜测原题。
- 重点检查论据是否支持论点、因果与条件是否充分、段落是否真正推进论证。
- 已确认的错字每3个扣1分，最多扣2分，并避免重复扣分。
- 纯文本不能核验手写字迹；识别不清的字不会直接作为错字处罚。

### 论证有效性分析

```text
请使用 $argument-validity-grader 批改我的论证有效性分析作文。

考试类型：
[经综或管综]

原题论证材料：
[粘贴完整原题材料及题面附带的写作要求]

我的文章：
[标题与完整正文]

参考答案：
[可选；没有参考答案也可以批改]
```

反馈包括：分项评分、材料考点梳理、作文分析要点核验、论证与结构语言评价、关键句段修改。

- **完整原题材料与完整作文缺一不可，缺项不批改，也不给暂定分。**
- 管综：分析评论内容16分，论证程度、结构与语言综合14分，总分30分。
- 先独立全面检查材料，按通常可能有6~7个候选点的预期排查，但不硬凑数量，也不要求作文写满全部候选点。
- 内容取最好的4个独立分析：只有推理对象准确、缺口成立、理由具体且说明削弱关系，才算完整命中并得4分。4个完整命中取得内容16分；只报术语、泛泛反问或重复换说法不能充数。
- 单点区分完整命中4分、基本命中3分、部分命中2分、仅定位1分、未命中0分。该细化及6~7点检查预期属于本地训练规则，不冒充官方补充细则。
- 合理且成立的分析即使不在参考答案中，也可以得分。
- 综合质量项的一类卷须有持续、具体、有力的分析；不能仅凭段落整齐、语言流畅取得高档分，同一缺陷不机械重复扣分。
- 四类卷仅对应14分的综合质量项，不是整篇总分的档位。
- 经综：先按30分制评定，再将总分乘以 `2/3`，满分20分；不采用论说文的18分封顶。

公开资料依据、命题检查路径和自拟评分示例见[命题要点与严格评分校准](skills/argument-validity-grader/references/exam-points-and-calibration.md)。公开资料支持选择若干有效分析点，不规定每份材料固定6~7点；经综同比例换算沿用本项目的训练量表。
